# mnist-digit-recognition
Handwritten digit recongnition using CNN and Tensorflow
Проект по распознанию рукописных цифр от 0 до 9 с использованием нейронных сетей и библиотеки TensorFlow/Keras.

*О проекте*

Цель проекта - разработать и сравнить две архитектурных нейронных сетей для классификации изображений рукописных цифр:
- *Полносвязанная нейронная сеть(Dense) - базовая модель, использующая полносвязнные слои.
- *Свёрточная нейронная сеть(CNN) - модель, использующая свёрточные и пулинговые слои для извлечения признаков изображений.

В качестве набора данных используется MNIST.
